GOLDLINE AUTO QUOTE — INSTALLATION

1. Host all files from this folder on a secure HTTPS website (e.g. GitHub Pages, Netlify). Opening the HTML directly as a file will NOT install the PWA.
2. Open that HTTPS address in Chrome on your Android phone.
3. Chrome menu (three dots) > Install app (or Add to Home screen).
4. Launch Goldline Quote from your home screen. Once loaded online, the app can work offline.

The standalone preview HTML file works as a calculator without hosting, but has no full PWA installation capability. Estimates only; taxes and fees vary.
